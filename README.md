# IBPS SO IT Officer — Mains 2026

A focused, static countdown dashboard for the **IBPS SO IT Officer Mains**, targeted for **1 November 2026, 09:00 IST**.

## Deploy free

This is intentionally a no-build site. Upload these files to any static host, or use GitHub Pages:

1. Create a new GitHub repository and upload this project.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Save—the dashboard will be live at the provided GitHub Pages URL shortly.

To preview locally, simply open `index.html` in a browser.

## Add another exam

Open `app.js` and add an object in the `exams` list (an example is already included as a comment). A tab is created automatically. Set `shortName`, `title`, `target`, the ISO 8601 `date`, and the date you began preparing (`startDate`).
